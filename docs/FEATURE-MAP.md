# 功能对齐地图

> 定位原则（用户定，2026-08-07）：**假设我们的用户就是 TokenTracker 和 All API Hub 的用户是同一种人。**
> 用量侧的功能与页面向 TokenTracker 靠，中转站侧向 All API Hub 靠——不盲目降级也不盲目升级。
> 本文是逐功能的对照表；排期见 [ROADMAP.md](ROADMAP.md)。状态：✅ 已有 · 🔨 进行中 · ⬜ 规划 · 🔭 远期 · ✂️ 有意不做（须写理由）
